Raspberry pi

Restart a service

sudo systemctl restart ai-rover.service

Stop a service

sudo systemctl stop ai-rover.service

Log a service

journalctl -u ai-rover.service -f

Enable SSH

sudo raspi-config

Navigate to:

Interface Options
    SSH
        Enable

Or simply:

sudo systemctl enable ssh
sudo systemctl start ssh

Check:

systemctl status ssh
