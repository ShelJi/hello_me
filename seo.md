# SEO optimization requirements

Scope: the supplied Sage report for the homepage at https://shelj.in/. The reported baseline is SEO 61, GEO 58, AEO 39 and AI View 80. These are the report's measurements, not new audit results.

| What to optimize | Why |
| --- | --- |
| Internal linking, reported score 29 | Connect the introduction to projects, experience, skills, notes, resume and contact so visitors and crawlers can find related information through descriptive links. |
| Thin content, reported 262–269 words | Add useful explanations of actual engineering work, project scope and technologies. Exceed the audit's 300-word threshold through helpful content rather than repeated keywords. Word count alone does not establish quality. |
| Meta description, reported 172 characters | Use a concise, accurate description within the audit's 50–160-character range and align social descriptions with the page. Search engines may rewrite or truncate snippets. |
| Missing H1 and uneven heading hierarchy | Give the homepage one clear main heading identifying Sheljin and his engineering focus. Use section headings and subordinate headings to make the content easier to navigate and interpret. |
| Publication and modification signals | Expose a truthful last-updated date in visible content, page metadata, structured data and the sitemap. Include an original publication date only when it can be verified; inventing one would misrepresent the page's history. |
| Nine images without lazy loading | Defer below-the-fold media to reduce unnecessary initial downloads. Keep initial-viewport media eager so visible content is not delayed. |
| Ten reported render-blocking scripts | Defer external scripts while retaining dependency order. Move dependent inline initialization into a deferred file so animation and game features continue to work. |
| Table without header cells | Remove or repair the third-party calendar markup responsible for the tabular widget. Real data tables need descriptive header cells and appropriate scope so readers and machines can identify relationships. |
| Missing image alternative text | Give meaningful images useful alternatives, and use empty alternatives only for purely decorative images. Prevent third-party markup from adding unlabeled images. |
| Empty or unlabeled links | Give icon links readable text that describes their destination. Make links useful to people, screen readers and crawlers without relying on an icon alone. |
| Limited structured data | Connect the existing Person entity to an accurate website and profile page, and describe visible FAQs. Use schema types that match real content rather than adding unrelated Article or Organization markup for a score. |
| Weak answer targeting and snippet readiness | Add concise questions and direct answers about engineering work, projects and contact methods so information is easy to find, quote and understand. |
| Reading ease 57 and moderate word complexity | Use short sentences and plain explanations of technical terms while preserving necessary engineering names and accurate project details. |
| Missing speakable property | Identify brief, visible summary and answer passages suitable for text-to-speech. This is descriptive markup; it does not promise voice-assistant inclusion. |
| Agent Interactivity / WebMCP score 18 | Make public information and destinations available through semantic HTML and ordinary links. Add an agent tool only if the site offers a real action with a defined interface; a read-only portfolio does not need invented tools to satisfy a heuristic. |
| AI View structure and crawl signals | Keep the topic, identity, heading outline, media labels, canonical URL, language and crawl directives consistent and available in initial HTML. |
